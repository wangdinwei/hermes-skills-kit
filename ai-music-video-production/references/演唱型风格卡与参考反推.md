# 演唱型 MV：从参考素材反推风格卡

用于用户发来一支参考视频/一张截图说「类似的」、或直接说「先把风格定下来」的时候。
目标不是听懂形容词，是**输出一张六项写死的风格卡**。

## 一、参考素材解码流程（四步，全程可量化）

```bash
# 1) 客观骨架：画幅 / 时长 / 帧率 / 有没有音轨
ffprobe -v quiet -print_format json -show_format -show_streams ref.mp4

# 2) 形态：数剪辑点 → 均镜长（这是“一条长镜”还是“快切”的唯一客观证据）
p=$(ffmpeg -hide_banner -i ref.mp4 -vf "select='gt(scene,0.3)',showinfo" -vsync 0 -f null - 2>&1 | grep -c pts_time)
echo "剪辑点=$p"

# 3) 抽 4–5 帧拼一张图，不要逐帧单发
#    -ss 取 5%/25%/50%/75%/95% 处，hstack+vstack 拼 2×2

# 4) 一次问完（见下方提问模板），不要分多轮
```

**提问模板（逐项点名，否则视觉模型只回“很高级的电影感”）：**

> 逐项回答：① 真人实拍 / AI 写实 / 3D？AI 感具体体现在哪？② 妆造细节（衣服材质纹样、发型、头饰、耳饰）③ 脸占画面高度约多少、半身还是大特写、视线朝哪 ④ 是否在唱歌（嘴型）⑤ 光的方向/色温/明暗分割 ⑥ 背景是什么、虚化程度 ⑦ 色调/颗粒/暗角 ⑧ 字幕与文案的位置和字体

## 二、实测解码结果：抖音“年代感 AI 演唱”这条赛道

两条对标（一条老者 live 长镜、一条年轻女子胸像）表面完全不同，参数却高度一致 —— 这就是可复用的风格卡：

| 项 | 取值 |
|---|---|
| 画幅 | 竖屏 9:16（对手 868×1920；我们出首帧 832×1472 / 成片 1072×1920）|
| 景别 | **半身胸像，脸占画面高 25–35%** |
| 光 | **侧逆光勾边 + 正面柔补**；主光从画面侧后 45° 进；暖 3200–3600K；阴影偏青灰 |
| 环境 | 真实老旧环境（斑驳旧墙＋旧木窗 / 录音棚鼓镲 / 夜渡口旧船），**中虚化，背景必须有信息量** |
| 调色 | **低饱和暖灰**（枣红/米黄/灰褐）＋ 35mm 颗粒 ＋ 轻微暗角 ＋ 柔焦；**不追求锐利** |
| 造型 | 极端具体的年代道具，写死材质（棉布/毛绒/旧金属）：碎花棉袄＋双麻花辫＋红绒球头饰＋大红花耳环；或白长须＋旧布帽＋褪色青衣＋贝壳手串＋多层项链 |
| 演唱 | 女声半垂眼不看镜头，男声直视镜头；嘴都在动 |
| 包装 | 底部居中**复古衬线（宋/仿宋）**字幕＋顶部大字标题＋一句扎心文案 |
| 人物动线 | **机位完全不动**，靠人自己的头/表情/口型撑满全片 |

**两条反直觉但要记住的结论：**

1. **AI 感可以被容忍。** 两条对标都有磨皮、发丝融合、花纹重复、材质简化，平台照样给 1 万～2.9 万赞。这条赛道不需要“看不出是 AI”，**别把预算砸在去 AI 味上**，砸在造型道具和光上。
2. **脸不要占 60%。** 60–70% 是“怼脸开唱”（音频驱动数字人那套）的构图；live/年代感要的是“一个人站在环境里唱”，半身 + 麦克风 + 虚化环境才出故事感。写风格卡时先把这条写到脸上。

## 三、出图给用户“感觉一下”（风格测试图组）

风格讨论用文字来回几轮都不如直接给图。做法：同一个人物、同一套造型，**只换光和调色**，一次出 4 张：

1. 写一条固定 SUBJECT 串（年龄/胡须/皮肤质感/服装/道具/嘴微张在唱）＋ `Both hands out of frame`；结尾 `85mm f/2, shallow depth of field, ultra sharp facial detail, no text, no watermark`
2. 四个 STYLE 段分别追加：旧墙窗光低饱和暖灰 / 录音棚暖琥珀 / 夜渡口青蓝＋暖灯 / 褪色老照片棕黄
3. **一次全部提交进 ComfyUI 队列**（本地 FLUX3，竖屏 `EmptyFlux2LatentImage 832×1472`，steps 28 / cfg 1.0 / euler+simple），4 张 20 多秒出完；不要逐张等
4. 拼一张横排对比图先自己过一遍 `vision_analyze`（查脸崩/多指/造型缺件/侧逆光真假），再单张原图发给用户
5. 交付话术：标明每张的光/调，给出自己的取舍（“3 当主色、2 当副歌爆发的光”）—— 用户要的是能选的东西，不是分析

**取舍经验：** 主歌压青蓝冷调、副歌切暖琥珀，同一机位不动只换光，一支慢歌就有了起伏 —— 比加运镜便宜且不伤口型。

## 四、固定电子人（虚拟歌手）系列的落地口径

用户说要“固定几个电子人像明星一样一直唱不同的歌”时：

- **一个人 = 一张脸 + 一把嗓子 + 一套年代身份 + 一个字体**；观众记住的是“那个海边唱民谣的老头”，不是“那个 AI 角色”。
- 先定 **2 个**（一男一女），不是 5 个：每人一份人设卡（名字/身份/造型道具清单/嗓音 prompt 串/调色/字体/禁用项）。
- 前 10 支不追电影感，追**统一感**（同一张脸、同一字体、同一调色）。系列的可识别性来自重复，不来自单支质量。
- 目录按人分：`音乐制作/电子人/<名字>/`（人设卡、形象、音色、作品）。

## 五、模块化片场：人 × 景 × 道具（系列的地基）

用户原话的模型：「万变不离其宗，人物景都可以换，景要多元化，多备一些放着」。

**宗 = 这批人 + 这套美术；变 = 场景、道具、曲风。** 资产不是「一个人的形象」，是组合卡：

```
资产库/
├── 人物库    V1–V4 × 每人 3–5 套造型（覆盖现代 / 复古 / 古装三档）
├── 场景库    12–16 个，每个一张母版图 + 3–6 个机位图
├── 道具库    麦、酒杯、筷子、行李箱、雨伞、旧相框、吉他……
└── 组合卡    V1×酒店、V3×天台、V2×出租屋……（人已站在景里的定妆图）
```

**场景按情绪功能分类，不按装修风格分类** —— 观众看的不是「一间便利店」，是「一个人在深夜便利店里开口」。

| 功能 | 场景 |
|---|---|
| 孤独 | 深夜便利店、出租屋床边、空地铁、天台 |
| 压抑 | 办公室隔间、电梯、地下车库、堆满纸箱的出租屋 |
| 体面与崩塌 | 酒店房间、宴会厅走廊、洗手间镜前 |
| 烟火气 | 夜市饭桌、大排档、菜市场、老家院子 |
| 回忆 | 旧教室、录像厅、老屋堂屋、理发店 |
| 在路 | 车里、渡口、站台、人行天桥 |

**六条常量（换任何场景都不变，这是「像一个厂牌」的全部来源）：**
1. 色彩基底低饱和 + 一个专属色点缀（每人一色，不混用）
2. 光：侧逆光为主光 + 正面柔补，暖 3200–3600K，阴影偏青
3. 镜头：同一焦段（35 或 85mm），浅景深，不用广角畸变
4. 质感：35mm 颗粒 + 轻微暗角 + 柔焦
5. 构图：竖屏 9:16，半身/中景，脸占 25–35%，人不居中
6. 字体：底部复古衬线歌词 + 顶部大字标题，字号字距固定

**选角判据（一首歌到手怎么分主配）：** 歌词视角（我/我们、男/女）→ 情绪温度（冷/暖/狠/冲）→ 副歌最高音落在谁的音区 → 是否要和声 → 场景里要不要「围观者」（要就把剩下的人放前景虚焦）。

**群像约束（硬）：** 视频模型会把画面里所有人的嘴一起驱动，所以「四个人一起唱」只能靠**单人镜交替**或**分屏假同框**；配角有戏靠递麦、和声张嘴但不给正脸、前景虚焦肩膀/后脑勺、观众席反应。

## 六、场景 / 空镜提示词：土不土只差四件事

> 用户原话：「你每次出的那种场景图都很土、很俗，去看看别人家的景是怎么写的。」

实测 132 条高赞画布的图片提示词：字符数中位只有 **170 字**，影调词（film grain 26% / bokeh 18% / depth of field 18% / 35mm 18% / cinematic 15%）只是打底。真正拉开档次的是四件事，**都不是形容词**：

1. **一个具体到反常的物** —— 不是「货架」，是「还在冒气的关东煮锅 + 靠在柜台的湿伞 + 地上一摊反射灯管的水」。它是「人刚离开的证据」，场景才有戏
2. **光要有来源和状态** —— 不是「冷白荧光」，是「过曝的自然光从开裂的天窗倾泻下来」
3. **空气里要有介质** —— 蒸汽、尘埃、水汽、雨痕、薄雾（电影感最便宜的一半）
4. **锁两种颜色并定占比** —— 冷青白 90% vs 暖琥珀 10%（只在关东煮那一块）

**写法顺序：** 空间（什么地方、什么时间）→ 反常的具体物 1–2 件（带交互状态）→ 光的来源与状态 → 介质 → 两种颜色与占比 → 影调参数 → 负面清单（`no text, no letters, no signage, no logo, no watermark, no people, no cartoon`）。

**影调收尾模板：** `Cinematic still photography, anamorphic 35mm, shallow depth of field with soft oval bokeh, fine film grain, lifted matte blacks, gentle bloom, slight vignette, no people.`

**反例（为什么会土）：** 只写功能（「深夜便利店、冷白荧光、货架、冷青调」）—— 没有物、光没有来源、没有介质，出来就是干净平淡的商品图。

**同一招也治「主题色没落地」：** 写「冰蓝」只给冷光时，画面里几乎没有冰蓝。**主题色必须落在实物上**——发丝挑染、丝巾、针织内搭、拼色包边、耳饰；否则模型只会用打光暗示，成图看不出标识色。造型确认时逐张核「这个颜色在哪件东西上」。

**空镜 vs 组合卡：** 场景母版写死 `no people`；要做人 × 景组合卡时，景的那一段**逐字复用**母版原文，只加「人站在哪、朝向、光落在脸哪一侧」。同场景多机位从母版 i2i 衍生（denoise 0.42–0.55），不要重新文生图。
