# 镜头提示词规格（分镜写词的执行标准）

> 写任何一镜的提示词之前先看这份。它不是「描述画面」的模板，是「给模型下施工图」的规格书。
> 写得像散文 → 出图靠抽卡；写得像规格书 → 出图可复现。

## 一、开工前先定：全局锚点表

这张表没定就出图，后面必然返工。四个锚点：

| 锚点 | 固定什么 | 写法要求 |
|---|---|---|
| **主体锚点** | 角色外貌/服装/道具的固定描述 | 至少锁 5 项：脸型、发式、服装颜色与款式、体型、气质关键词 |
| **场景锚点** | 环境特征/光线条件/色调基调 | 写清空间布局（门窗位置）与主要光源方向 |
| **光效锚点** | 全片主色调/布光风格/色温 | 一个值贯串全片，不因镜头情绪变化而改 |
| **声效锚点** | 环境底噪/音乐风格/特效音 | 只列场景里真实存在的声音 |

**这张表要贴进每一个镜头的提示词**，不是写一次就完事。

## 二、单场提示词 11 字段

一段戏一条提示词，按这 11 段写，一段都不能少。

### 1. 【场次名称】
简称点明这段戏，如【对峙】【揭底】【和解】。

### 2. SCENE CONTEXT
```
时代背景：[锁定具体语境，不要泛写「现代」]
时间：[白日/黄昏/夜间，精确到时段]
地点：[具体场所]
剧情衔接：[上一场结尾状态]→[本场开场状态]，[承接关系]
本场核心戏剧目标：[背后的心理/权力/信息博弈，不是表面动作]
```
**写法**：戏剧目标写内在动机。写「他要在不被察觉的前提下摸清对方底牌」，不写「他走出门」。

### 3. ACTIVE REFERENCES（锁人物）
```
@{{节点key}} — 锁定：[脸型/发式/体型/服装/气质，列出不可修改项]
```
- 每个人物至少锁 5 项
- 场景锁空间布局 + 主要光源方向
- 道具锁到「精确形制」（尺寸、材质、是否可替换）
- **节点 key 必须真实存在**，不接受文字描述替代，不接受占位符

### 4. CONTINUITY RULE（防穿帮 + 防越轴）
```
道具因果链：[道具在哪、何时出现、何时可以消失]
人物出入场顺序：[谁先出现、谁后出现、谁始终在场]
屏幕方向稳定性：[人物左右位置，写死]
身份关系稳定性：[层级关系，防止把下属演成老板]
空间连续性：[镜头切换时空间逻辑]
```
**这一栏是越轴的唯一解药。** 双人对峙戏尤其必须写死「谁在画面左侧、谁在右侧」。

### 5. FORMAT
```
总时长：[秒数]
剪辑模式：[Timed multishot / 单镜]
语言：[语体要求]
NO项：
- 无旁白 / 无字幕 / 无英语 / 无配乐煽情 / 无特效 …
```
NO 项要具体到「不要做什么」，不要写「风格干净」。

### 6. CAMERA/EDITING（时间码分镜）
```
[整段调度逻辑概述：情绪或权力转折的起承转合，2–3 句]

0.0s–Xs｜镜头1｜[场景/位置]
  FOV：[35mm广角 / 85mm中长焦]
  景别：[特写/近景/中景/全景/大全景]
  动作：[可拍到的身体/手/物件/视线，具体到部位]
  台词：[原文一字不差]
  表演要点：[可观察的行为]
  剪辑标记：[HARD CUT / MATCH CUT / 无]
```
**表演要点必须可观察**：写「视线是扫视而不是盯视，像在看街景」，不写「他很警惕」。

### 7. PERFORMANCE LOCK（防演过火）
```
[角色]：
  不要演成：[类型化的错误方向]
  而要演成：[正确的表演基调]
  关键动作边界：[具体动作的上限]
```
**范例**：
```
甲方：
  不要演成：脸谱化的黑心甲方，狞笑、指人鼻子
  而要演成：一个习惯了被捧着的人，威压自然流露，不需要刻意
  关键动作边界：手指不超过胸口高度；不得拍桌、不得指镜头
```
这一栏对 AI 尤其重要 —— 模型默认会往「戏剧化」方向演，不写就会过火。

### 8. AUDIO
```
环境声：[真实存在的环境声]
道具声：[什么道具、什么动作、产生什么声音]
呼吸/气息：[关键情绪节点的呼吸处理]
台词音量处理：[音量/混响]
明确排除：[不要出现的声音]
```
只列场景里真实存在的声音，不写「配乐烘托气氛」。

### 9. LIGHTING（连稳定性一起写）
```
色温：[如 4800K，偏暖白]
主色调：[暗部青黑，亮部暖肤色，整体低饱和]
光源方向：[主光来源与方向]
特殊光效：[轻微 bloom，非 HDR 过曝]
稳定性要求：基础光效不因剧情紧张程度改变，不得在对峙场景突然压暗或加红光
```
**最后那句是系列不飘光的保证。** 缺了它，同一场戏不同镜头会拿到不同色温和明暗，观众说不出哪里怪但会不适。

### 10. ENDING FRAME（连续性的链条）
```
构图：[结尾停留的画面]
人物位置：[各人物在画面中的位置]
道具状态：[关键道具的最终状态]
情绪基调：[这个结尾传递的情绪]
下一场衔接提示：[这个尾帧如何作为下一场的连续性起点]
```
写完一场立刻记下尾帧状态，下一场拿它当开场。不记就只能硬切，观众会「咦」一下。

### 11. NO/LOCKS（四类禁止项汇总）
```
视觉禁止：不要英语文字 / 不要现代元素 / 不要凭空生成未引用的道具 / 不要夸张表情 / 不要特效
表演禁止：不要类型化的坏人表演 / 不要类型化的好人表演 / 不要过度肢体语言
音频禁止：不要背景音乐 / 不要旁白 / 不要现代音效
叙事禁止：单条提示词不跨超过 3 个场景 / 未出场角色的声音不得出现在画外
```

## 三、镜头的空间铁律（五条硬约束）

违反任何一条，画面就废。这些是运镜的单一事实源：

1. **轴线同侧 180° 半区** —— 机位不许越轴，方向感不许翻转
2. **中景及以上禁止侧面 90° 正拍** —— 必须用 **30–60° 斜角**，除非要的是一股硬邦邦的证件照感
3. **景别衔接** —— 不许同景别硬接；跨两级以上跳转必须有引导；**特写与全景不许直接互切**
4. **景别对动作节奏** —— 大景别拍蓄力，小景别拍接触帧
5. **多人同框比例** —— 同一地面基准线 + 同一镜头焦距比较，否则透视差会被读成「他比他高一头」

**外加一条**：运镜方向要和风况、主光方向、阴影走向协调；快速横移/甩镜要写明对云雾、尘埃、发丝、衣摆的二次扰动。

## 四、10 条铁则

1. 台词一字不差，情节 100% 还原，不删改不意译
2. **画幅自动适配**：竖屏写 `9:16 aspect ratio, vertical frame, mobile-first composition`
3. 物理写实：受力反馈真实（皮肤形变/汗飞溅/躯干晃动）
4. **严格 180° 轴线，禁止跳轴**，人物站位始终统一
5. 每个分镜能直接指导实拍或 AI 生成
6. 节奏张弛有度，禁止全程匀速
7. **每镜单一信息点，单镜 ≤15s**
8. **提示词完整可用**，不需二次修改
9. **防 AI 崩坏**：提示词里写防穿模/防手指畸形/防关节扭曲
10. 全片风格统一，按全局锚点表执行

## 五、技术参数尾巴（固定写法）

```
竖屏：cinematic, 9:16 aspect ratio, vertical frame, mobile-first composition,
      film grain, shallow depth of field, Kodak Vision3 color grading

横屏：cinematic, 16:9 aspect ratio, 2.39:1 widescreen,
      film grain, shallow depth of field, Kodak Vision3 color grading
```

**别只写像素尺寸（1080×1920）** —— 缺 `mobile-first composition` 模型就不会按手机竖屏的构图逻辑思考，出来的画面像横屏裁成竖的。

电影感加强（可选）：f/1.8 浅景深 → 橙青色调 → 35mm 颗粒 → 180° 快门运动模糊 → 丁达尔体积光 → 中心锐利边缘柔化 + 自然暗角。

## 六、12 列分镜表（输出格式）

```
| 镜号 | 景别 | 镜头角度 | 运镜方式 | 构图方式 | 画面内容 | 台词 | 音效 | 光效 | AI提示词 | 时长 | 导演备注 |
```

**标准值**：
- 景别：ELS 大全景 / LS 全景 / MS 中景 / MCU 中近景 / CU 近景 / ECU 大特写
- 角度：Eye Level / Low Angle / High Angle / Dutch Angle / Bird's Eye
- 运镜：Static / Dolly In / Dolly Out / Pan / Tilt / Tracking / Follow / Orbit / Crane / Handheld / Steadicam / Slow Motion
- 构图：Rule of Thirds / Symmetry / Frame-in-Frame / Leading Lines / Diagonal / Negative Space / Crowded

**运镜写「方向 + 速度 + 动机」，不只写 `slow push-in`。** 例：`Dolly In，慢速，从胸口推到面部，动机是压迫对方`。

## 七、最常见的五个漏写（按危害排序）

| 漏写 | 后果 |
|---|---|
| **LIGHTING 稳定性要求** | 同场戏不同镜头色温/明暗不一致，全片像拼的 |
| **CONTINUITY RULE 屏幕方向** | 双人对峙越轴，两人位置跳 |
| **PERFORMANCE LOCK** | 模型往戏剧化方向演，表情过火 |
| **ENDING FRAME** | 镜头之间硬切，衔接生硬 |
| **mobile-first composition** | 竖屏构图按横屏逻辑生成 |

**自查方法**：镜头表写完后，随便挑两镜的提示词并排看，如果除动作描述外没有任何一句是重复的（锚点串、光效、方向），那说明没有统一约束，全片一定会飘。
