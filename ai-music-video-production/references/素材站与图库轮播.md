# 图库素材站：可用性、下载方式、授权红线

> 做图文轮播 / 氛围型 MV 时用。先看「今天能不能不注册就拉到货」，再谈配额。

## 一、实测可达性（本机网络下）

| 站 | 状态 | 最高清 | 需要 key？ | 授权 |
|---|---|---|---|---|
| **Coverr** | 可直接抓 | **1920×1080** | 不要 | Coverr Free License，可商用无需署名 |
| **Mixkit** | 可直接抓 | 1280×720（1080 路径不存在） | 不要 | 免费区可商用，部分需署名 |
| Pixabay API | 需登录 | 1080p+ | 要（登录后自动显示） | Pixabay Content License |
| **Pexels API** | **暂停发放新 key** | — | — | — |
| 光厂 VJshi | 页面可开 | 1080p/4K | 要账号/付费 | 国内题材最对味 |

**Pexels 的新 key 发放目前是暂停状态**（官方帮助页原文：*New API key issuance is currently paused.*）。不要再把用户引到 `pexels.com/api/new/` 去填表——他在那里只会碰一鼻子灰。**Pixabay 的 key 是登录后直接显示在 `https://pixabay.com/api/docs/` 页面参数表里，不用申请表单。**

## 二、不注册的两个站怎么抓

**Coverr**：搜索结果页 HTML 里就有 CDN 直链，把 `360p` 换成 `1080p` 就是高清版：

```python
html = urlopen("https://coverr.co/s?q=" + quote(kw)).read().decode("utf-8","ignore")
slugs = re.findall(r"cdn\.coverr\.co/videos/([a-z0-9\-]+)/360p\.mp4", html)
# 下载：https://cdn.coverr.co/videos/{slug}/1080p.mp4   （720p 同名可用）
```

**Mixkit**：结果页里直接能正则出 mp4，但只有 `-360` / `-720` 两档，`-1080` 返回空文件：

```bash
curl -s -A "Mozilla/5.0" "https://mixkit.co/free-stock-video/airport/" -o /tmp/x.html
grep -oE 'https://[^"]+\.mp4' /tmp/x.html | sort -u
```

**下载必验三件**：`stat` 文件 >500KB、`ffprobe` 宽 ≥1280、时长 >2s。小于这个尺寸直接删 —— 小于 1280 宽裁成 720×1280 竖屏必糊。

## 三、入库纪律（比下载重要）

1. 每张/每条落一组**语义标签**（不是描述）：`老屋 土房 农村 秋` / `账本 写字 钢笔 纸`；不要靠文件名
2. 建 `stock_manifest.json`：`{tag, kw, slug, path, w, h, license}` —— 后面排镜只读这个表
3. 选图时先看**能量位置**（低能量段用空镜/远景，副歌用特写/质感镜头），再按歌词锚点取图
4. 下载后抽帧拼 contact sheet 一次性过 vision，不要逐张问

## 四、授权红线

- CC0 / Coverr Free / Pixabay Content License：可商用、可裁剪、可二创，**不可转售原始素材本身**
- 标 `CC BY` 的要署名（片尾/简介里写）
- 带**清晰可辨真人脸**的素材用于商业广告要谨慎（肖像权，不是版权）
- 带**商标/品牌 logo**（机场航司 logo、酒店品牌）的镜头避免特写；需要就用虚化或重构图
- 素材平台上的「编辑用途（Editorial Only）」素材**不能用于带货/广告**

## 五、搜什么词（命中率高）

| 要什么 | 英文 | 中文站 |
|---|---|---|
| 机场/登机 | `airport terminal`, `boarding pass`, `departure board`, `airplane window` | 机场 航站楼 登机
| 旧楼/洋楼 | `old building facade`, `vintage mansion exterior`, `old apartment window` | 老洋房 民国建筑 老楼
| 农村老屋 | `old rural house`, `abandoned house`, `village road` | 土房 老屋 村庄
| 手/劳作 | `old man hands`, `worker hands closeup` | 老人的手 农活
| 城市夜 | `city night rain`, `street lamp` | 夜雨 街灯

需要**竖屏**就加 `vertical`；或者拿 4K 横素材自己裁（横素材宽高比太大时只能裁出很小一块，先算：裁剪后宽 = 高×9/16，不够 720 就别用）。
