# 智能体接 IM 渠道对照（企业微信 / 个人微信）

> 2026-10 快照。版本号和菜单路径随产品更新会变，动手前先核当前客户端。

## 一、先分清两件事

| | 通道 | 替身 |
|---|---|---|
| 是什么 | 你在 IM 里派活，它回结果 | 它替你收发别人的消息、管群 |
| 个人微信 | ✅ 有官方途径（见第四节） | ❌ 从未开放，任何方案都是外挂 |
| 企业微信 | ✅ 官方开放 API | ⚠️ 官方明确不允许机器人操控成员账号收发消息 |

**合规自动收发消息的唯一路径是企业微信客服 API**（或公众号／小程序客服 API）。个人号自动化违反《微信个人账号使用规范》，处理方式包含限制/禁止部分功能直至永久封号、回收账号。不要推荐「某协议不封号」那类方案——卖接口的不承担封号后果。

最实用的合规折中：**让 AI 只帮写、不代发**（人审后手动点发送）。效率提升大半，风险为零。

## 二、WorkBuddy × 企业微信（官方融合版）

前置条件三个都要满足，缺一个入口就不出现：

1. 企业微信 ≥ 5.0.12
2. WorkBuddy ≥ 5.8.0
3. 企业微信**已认证企业**，且登录 WorkBuddy 时**用企业微信身份**

步骤：企微左侧菜单栏「WorkBuddy」（小猫头图标）→ 领取并激活（限免名额，领完向管理员申请）→ WorkBuddy 客户端用企微账号登录 → 企微聊天列表里创建机器人 → 授权绑定 → 机器人以可对话身份进入企业通讯录。

**能力范围**：企业授权范围内的十大权限——消息、文档、会议、微盘、通讯录、邮件、日程等。可私聊、可拉群、可关联企微自带 AI 助手「大圆」。

**坑**：企微账号与原有 WorkBuddy 账号的**数据与用量状态不互通**，历史会话/技能/积分在新入口看不到。

**买哪个权限包**：旗舰版同一价格下有「WorkBuddy 版」与「企微联合版」两种权益套餐——前者强在开放平台／API／MCP 扩展（自家有业务系统、要自定义入口选它），后者强在企微原生打通（以企微为办公核心选它）。**价格一致，但迁移单向**，下单前定清楚。

## 三、自建机器人路线（不依赖官方融合版）

企微客户端 → 工作台 → 智能机器人 → 创建 → 手动创建 → 填名称/头像 → **API 模式创建** → 连接方式选**「使用长连接」** → 取 **Bot ID** 与 **Secret**（Secret 只显示一次，丢了可重新生成）→ 启动侧设环境变量。

这条路开放给任意机器人，不绑定某一家产品——**自建 Agent 接企微走这条**。别默认只有官方融合版一条路。

## 四、接个人微信：微信助理

前提：WorkBuddy ≥ 4.6.4，手机微信 ≥ 8.0.70。

步骤：WorkBuddy 左侧「助理」→ 齿轮图标进助理设置 → 找到「微信助理」→ 点连接 → 卡片下方出二维码 → 手机微信扫码。成功标志是卡片右上角变「取消连接」。

**不需要 App ID / App Secret，纯扫码**——这是与企微机器人路线的关键差异。

能力边界：你在微信里发指令 → **你电脑上的** WorkBuddy 执行 → 结果回微信。拿不到别人的消息、不能回客户、不能管群。定位是遥控器。

## 五、个人微信接开源框架：官方 ClawBot 插件

微信有官方 ClawBot 插件，支持把开源智能体框架接进个人微信：安装 CLI 后终端出二维码，手机微信扫码授权，通讯录出现「微信ClawBot」置顶联系人。零封号风险、无需公网 IP 和域名。

目前对接 OpenClaw 这一系。**本质仍是「你跟你的 Agent 对话」，不是代管别人的微信。**

## 六、企微群聊里真正能提效的动作

- **群消息转任务**：勾选相关消息合并转发给机器人 → 自动识别其中引用的在线文档、微盘文件、日程、待办、会议纪要并逐个读原文 → 输出谁负责什么、哪些已定、哪些待确认
- **未读收纳**：一句话整理未读消息与邮件，按「需处理／待跟进／其他」三类归纳 + 提炼待办
- **代发**：可代发文本/链接/图片/文件到内部单聊或群，**发送前必须在面板核对并确认** —— 这个 human-in-the-loop 不要关
- **产物回传**：分享直接回会话，或上传微盘沉淀成组织资产（区别于「只能存在本地文件夹、要手动拖进群」的旧形态）
- **定时任务** + 推送开关

## 七、管理员侧管控（选型时问对方有没有）

| 项 | 做法 |
|---|---|
| 名额与算力 | 后台一键分派名额、把控算力消耗 |
| 可见性 | 设应用可见性、群聊范围，禁用敏感接口 |
| 群白名单 | 安全模式绑群 ID 白名单 + 可选关键词白名单 |
| 数据边界 | 走企业账号体系登录，上下文不出企业 |
| 身份对齐 | 企微身份必须与智能体组织身份对应，否则 IM 入口成为**权限旁路** |
| 审计 | 成员/模型/技能/用量/日志统一管理 |

部署顺序：先配好 → 拉内部测试群跑 2~3 个任务 → 确认收发与执行正常 → 再向全员开放。

## 八、实测已知问题

- 长任务慢（总结一小时视频量级的任务可跑到十几分钟），中途会建议暂停，**选继续会重复消耗积分与配额**
- 涉及时间的判断会出错（时间幻觉）
- 定时推送有丢失
- 审批流、账号互通仍有残限制
