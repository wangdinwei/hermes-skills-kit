**为什么它能赢产品赛马**（逆向拆解结论，值得抄）：生产级 Agent 的差异不在模型，在四件工程手段 —— **骨架插槽**、**模式裁剪**（按场景裁剪提示词注入，而不是每轮背全量规则）、**分段注入**、**代码层安全禁令**（靠代码禁止危险操作，不靠模型自觉）。规则堆三四十条会让模型顾此失彼；每轮背几万 token 历史和全量规则会击穿成本。

## 三、通用 Agent 与垂直 Agent

- **Kimi OK Computer** — 给 Kimi 一台虚拟电脑：写代码、跑终端、部署网站
- **纳米AI**（360）— 超级搜索智能体，检索强
- **天工 Skywork Super Agents**（昆仑万维）— GAIA 榜曾登顶，Office 三件套+网页+播客一站式
- **MiniMax Agent** — 软件开发类任务表现突出
- **Genspark** — 华人团队（美），检索与软件开发强
- **心响**（百度）/ **元宝·ima**（腾讯）
- **实在 Agent** — RPA 路线，直接操作任意软件界面，信创/私有化，政企
- 垂直：**Lovart**（视觉设计，改稿不跑版）、**Medeo**（视频）、**YouMind**（长文写作）、**Flowith**（画布多线程）
